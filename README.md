# Домашнее задание к занятию "Платформа мониторинга Sentry" - `Вялов Владислав`


Задача 1: API Gateway
Предложите решение для обеспечения реализации API Gateway. Составьте сравнительную таблицу возможностей различных программных решений. На основе таблицы сделайте выбор решения.

Решение должно соответствовать следующим требованиям:

маршрутизация запросов к нужному сервису на основе конфигурации,
возможность проверки аутентификационной информации в запросах,
обеспечение терминации HTTPS.
Обоснуйте свой выбор.

Ответ

Nginx подходит для задачи, так как позволяет реализовать проверку токена через auth_request, перенаправляя подзапрос в сервис security . Это проще и прозрачнее, чем настройка плагинов Kong, и не требует изучения CRD Traefik. Nginx отлично справляется с терминацией HTTPS и базовой маршрутизацией, а его производительности достаточно для большинства задач .

Задача 2: Брокер сообщений
Составьте таблицу возможностей различных брокеров сообщений. На основе таблицы сделайте обоснованный выбор решения.

Решение должно соответствовать следующим требованиям:

поддержка кластеризации для обеспечения надёжности,
хранение сообщений на диске в процессе доставки,
высокая скорость работы,
поддержка различных форматов сообщений,
разделение прав доступа к различным потокам сообщений,
простота эксплуатации.
Обоснуйте свой выбор.

Ответ 

| Требование | RabbitMQ | Apache Kafka | NATS |

Кластеризация| Да (через кластеры и quorum-очереди) | Да (распределённый лог) | Да (кластеры) |
Хранение на диске | Да (persistent messages) | Да (по умолчанию) | Да (только в JetStream) |
Скорость | Высокая (тысячи msg/s) | Очень высокая (миллионы msg/s) | Очень высокая (in-memory) |
Разные форматы | Да (AMQP, MQTT, STOMP) | Ограничен (в основном свой протокол) | Ограничен (свой протокол) |
Права доступа | Гибкие (на уровне vhost/очередей) | Средние (ACL на топики) | Базовые |
Простота | Высокая (Management UI) | Средняя (требует ZooKeeper/KRaft) | Высокая |

Обоснование 

Хотя Kafka быстрее, она сложнее в эксплуатации и не так гибка в поддержке разных протоколов , которые могут понадобиться микросервисам. RabbitMQ обеспечивает надёжное хранение сообщений на диске (persistent), гибкую маршрутизацию и простую настройку прав через Virtual Hosts, что полностью покрывает требования задания.
